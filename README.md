# -windwahk-mod-speed-test-for-windows-
This is a windhawk mod, built for windows this mod used to test your internet speed without any dependencies (browser) right at your finger tips

Steps to follow:
open windhawk > create new mod > copy paste the source code > compile it > enable mod, settings user preferences


1. Insert network indicator left or right side
2. Color indication as your preference
3. Test measurement user choice either in (MEGABYTES/sec, or megabits/sec) (MB/s, Mb/s)
4.  User can access test by left mouse click on the network indication or using perform speed test by left click on wifi/network icon on taskbar
5.  Fluid animations
6.  No additional memory consumptions, 0.1MB
7. Unlike other flyout menu like quick settings, if u press anywhere on the screen while test is running window won't close automatically, it stays until the test is completed, after the test is completed if you click anythere on the screen it will close.
